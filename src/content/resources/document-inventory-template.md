Every business runs on documents: contracts, insurance policies, licenses,
handbooks, supplier agreements. Most of the time they sit quietly in a folder
or an inbox. The trouble starts when someone needs one in a hurry, or when a
renewal date passes unnoticed.

A document inventory is simply a list of the documents that matter, where they
live, and when they need attention. It takes an afternoon to set up and a few
minutes a month to maintain.

## What to record

The template includes these columns. Keep the ones that are useful to you and
delete the rest.

| Column | What to put in it |
| --- | --- |
| Document | A clear name, e.g. "General liability insurance policy" |
| Category | A short group: legal, insurance, finance, people, operations |
| Owner | The person responsible for keeping it current |
| Location | Where the current version lives — a folder path or system name |
| Version or date | How to tell the current version apart from old ones |
| Review by | When it next needs checking, renewing, or replacing |
| Sensitive | Whether it contains personal or confidential information |
| Notes | Anything someone covering for the owner would need to know |

## How to set it up

1. **Start with what would hurt to lose.** Contracts, insurance, licenses and
   anything with a renewal date go first. You can add everything else later.
2. **Record the location, not the document.** The inventory points to where
   the current version lives; it shouldn't become another copy.
3. **Give every document an owner.** A document without an owner is a document
   nobody reviews.
4. **Fill in "Review by" dates.** Sort by this column and you have a calendar
   of upcoming renewals.
5. **Mark sensitive documents.** It helps you decide who should have access to
   which folders.

## Keeping it current

Put a recurring 15-minute reminder in your calendar each month. Sort the
inventory by "Review by", deal with anything due in the next 60 days, and add
any new documents that arrived since last time.

Once a year, go through the whole list and remove anything that no longer
applies.

The template downloads as a CSV file, which opens in Excel, Google Sheets,
